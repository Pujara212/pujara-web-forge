

# Meet Pujara – Personal Portfolio Website

A modern, responsive single-page portfolio website showcasing Meet Pujara's professional experience, skills, and achievements.

## Design Direction
- **Dark theme** with accent colors (blue/teal highlights) for a professional developer look
- Smooth scroll navigation with animated sections
- Fully responsive – looks great on mobile, tablet, and desktop

## Sections

### 1. Hero Section
- Name, title ("Lecturer | Java Developer | Full-Stack Developer")
- Contact info (phone, email, location)
- Call-to-action buttons: "Download Resume" and "Contact Me"
- Animated entrance effects

### 2. About / Professional Summary
- Brief professional summary highlighting teaching + industry experience
- Profile photo placeholder (can be updated later)

### 3. Professional Experience (Timeline)
- Visual timeline layout showing all roles:
  - LJ Polytechnic (Current)
  - Sal Institute of Diploma Studies
  - HOPS Healthcare (Developer + Intern)
- Each entry shows role, company, dates, and key responsibilities

### 4. Projects Showcase
- Cards for HMIS and E-Commerce projects
- Tech stack badges on each card
- Key features listed with icons

### 5. Technical Skills
- Visual skill bars or categorized skill tags
- Categories: Languages, Web Technologies, Frameworks & Tools, Database, Concepts

### 6. Education
- B.E. Information Technology with CGPA highlight
- 12th and 10th results

### 7. Certifications
- Certified Java Developer – TOPS Technologies
- AICTE ATAL Faculty Development Program
- Visually distinct cards with dates

### 8. Strengths
- Icon-based grid showing key strengths (communication, problem-solving, mentorship, etc.)

### 9. Contact Section
- Contact form (name, email, message)
- Social/contact links
- Footer with copyright

## Key Features
- **Sticky navigation bar** with smooth scroll to sections
- **Mobile hamburger menu** for small screens
- **Scroll animations** as sections come into view
- **Dark/light mode toggle**
- **Downloadable resume** button
